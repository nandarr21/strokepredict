CARA KERJA

Proses Backpropagation

Tiga tahap utama yang terjadi dalam setiap epoch training model.

1. Forward Propagation

Data input (10 fitur kesehatan) diteruskan dari input layer → hidden layers → output layer menggunakan bobot dan fungsi aktivasi ReLU untuk menghasilkan prediksi awal.

Input (10) H1 (64) → H2 (32) → H3 (16) Output (1)
2. Backward Propagation

Loss (binary cross-entropy) dihitung antara output prediksi dan label sebenarnya. Gradien error disebarkan mundur ke setiap layer menggunakan aturan chain rule untuk menentukan kontribusi setiap bobot terhadap kesalahan.

3. Weight Update (Adam Optimizer)

Bobot diperbarui menggunakan Adam optimizer yang menggabungkan momentum dan adaptive learning rate. Formula: w = w - α * (m̂ / (√v̂ + ε)) di mana α adalah learning rate.

4. Early Stopping

Training dihentikan otomatis jika validation loss tidak membaik setelah 10 epoch (patience=10), dan bobot terbaik dipulihkan untuk mencegah overfitting.

Dataset & Preprocessing
Sumber Dataset

Stroke Prediction Dataset dari Kaggle oleh fedesoriano. Terdiri dari 5.110 record pasien dengan 12 atribut klinis termasuk informasi demografis, kondisi medis, dan gaya hidup.

Lihat di Kaggle
Tahap Preprocessing
  • Missing Value: BMI yang kosong (3,9%) diisi dengan nilai median kolom
  • Encoding: Variabel kategorikal dikonversi ke numerik (Label Encoding)
  • Imbalanced Data: Oversampling pada kelas minoritas (stroke=1) menggunakan resample
  • Normalisasi: StandardScaler untuk menyamakan skala semua fitur
  • Split Data: 80% training, 20% testing (stratified)
